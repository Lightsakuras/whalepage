> 调研时间：2026-10-18 ｜ 面向：小红书起号（0 → 1000 粉）
> 结论一句话：**这类东西能火是真的，但靠它直接卖钱是假的——它的作用是让你被看见，钱在后面的模板和定制里。**

**为什么这类东西能火（五条共性，必须同时满足 3 条以上）：**

1. **0 学习成本**——敲一下就有反馈，不需要说明书
2. **10 秒内出结果**——结果就是内容，用户替你传播
3. **绑定一种情绪**——功德（想骂人不敢骂）、发疯（撑不住）、缺德（笑了要赎罪）、社恐（已读不回）
4. **结果里要有「我」**——测试类必须能让用户说"这就是我"
5. **能被截图**——不能截图的东西传播不起来（这是硬指标）

电子木鱼最狠的地方：它同时满足 1、2、3、5，且**结果是个不断上涨的数字**——数字逼着人多敲一下。

## 二、市场的缺口在哪

现在供给有两类，都有明显缺陷：

- **一次性爆款**：火一个，作者没后续，账号废掉
- **工具站**：功能有，内容没有，没有"人"，涨不了粉

**缺口 = 一个「每周上新一个整活网页」的人。**

不是"工具站站长"，是**"整活网页作者"**这个人设。用户关注你不是因为需要工具，是因为想看你下周整什么活。

你的定位（账号简介直接用它）：

> 我做点没用但好玩的网页。每周一个，点开就能玩。

## 四、怎么实现（技术方案，很轻）

### 4.1 统一技术底座
- **单文件 HTML**：CSS + JS 全内联，零依赖，零构建
- **托管**：GitHub Pages（已有：`lightsakuras.github.io/whalepage/abstract/`）
- **一个玩具 = 一个目录**，`abstract/xxx/index.html`，做完 push 就有链接

### 4.2 三个必须掌握的技术点

**① canvas 出图（命门）**
没有"能保存的结果图"，这类网页的传播性直接砍半。
```js
const c = document.createElement('canvas'); c.width=1080; c.height=1440;
const x = c.getContext('2d');
// 画背景渐变 → 画标题 → 画内容 → 底部品牌
const url = c.toDataURL('image/png');
const a = document.createElement('a'); a.href = url; a.download = '结果.png'; a.click();
```
注意：中文字体用 `"PingFang SC","Microsoft YaHei"` 并手动换行（canvas 不会自动折行，我写了 `wrap()` 工具函数，在 `abstract/jingshen/index.html` 里可以直接抄）。

**② WebAudio 合成音（免素材）**
不想找音效文件就用振荡器合成——木鱼的"笃"= 正弦 430Hz 快速衰减 + 白噪声短脉冲，20 行代码。
```js
const o = ac.createOscillator(), g = ac.createGain();
o.frequency.exponentialRampToValueAtTime(180, t+0.075);
g.gain.exponentialRampToValueAtTime(0.0001, t+0.14);
```

**③ 复制文案**
```js
navigator.clipboard.writeText(txt)   // 必须 https 或 localhost，file:// 会失败
```
（这就是为什么必须部署到 Pages，本地双击打开是测不出来的）

### 4.3 复用策略：皮肤 + 卡片模板
所有玩具共用一套「暗色霓虹」皮肤（底色 `#08080b`、荧光绿 `#b6ff3c`、紫 `#7c5cff`、青 `#22d3ee`）和一套 canvas 卡片版式（顶部品牌 → 大标题 → 内容 → 底部签名）。
**新玩具 = 换内容 + 换交互，皮肤和出图逻辑直接复制。** 熟练后 1–2 小时一个。

## 五、变现：单价 10 元以内怎么走量

**先说清楚一件事**：这类玩具本身**几乎不能直接卖钱**。用户来玩是因为免费。
能卖的是"**想拥有一个属于自己的**"——这才是付费动机。

按「离钱近」排序：

| # | 商品 | 价格 | 目标客户 | 走量逻辑 |
|---|---|---|---|---|
| 1 | **同款整活网页源码包**（含 5 个玩具） | ¥9.9 | 也想做内容但不会写代码的博主/学生 | 一份改文案就能发，价格低于自己学的时间成本 |
| 2 | **定制改名版**（把他的名字/公司/对象写进玩具） | ¥9.9–19.9 | 送对象、送朋友、公司年会 | "给对象做的网页"是刚需，节假日爆 |
| 3 | **测试链接按次卖**（生成专属链接） | ¥0.9–1.9 | 想发给群里玩的人 | 实测案例：2 个月 24.3 万单 |
| 4 | 网页定制（正经做站点） | ¥299–699 | 极少数 | 从 1–3 里筛出来，不要主动推 |
| 5 | 流量分成 / 小红书店铺佣金 | — | — | 有量之后自然有 |

**关键判断**：第 1、2 项是真正能"走量"的——因为**边际成本为 0**，卖 300 份和卖 3 份的工作量差不多。
第 3 项需要一点自动化（生成唯一链接），可以后期再做。

**不要做的事**：¥10 以下的**定制开发**。改一次 2 小时，时薪 5 块，做三天就想放弃。

## 六、风险（提前说清，别踩）

1. **48 小时就被抄**——应对：连发不断更，靠"系列 + 人设"取胜，不靠单个作品
2. **不做违禁内容**：政治、宗教宣传、地域黑、性别对立、实名恶搞学校/公司/同学——一律不碰。**电子木鱼是情绪玩具，不是宗教内容**，文案里不要出现"佛祖保佑灵验"这类
3. **测试类的伪科学争议**——页面里必须写"不是心理测评，是个乐子"，这既是保护也是更讨喜的调性
4. **站外链接限流**——小红书正文不要放链接，链接放主页/评论/私信自动回复
5. **声音自动播放**——大多数浏览器要求先有用户交互，所以木鱼必须在"第一次点击"之后再初始化 AudioContext（我已经这么写了）

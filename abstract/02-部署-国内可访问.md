# 部署：让链接在国内手机上能直接打开

> 结论先行：**国内"免费 + 免备案 + 稳定直连"的静态托管，基本不存在。**
> 这不是没找对服务商，是政策与商业共同决定的。所以要在「花钱/花时间」和「体验」之间选一个。

---

## 一、为什么不建议继续用现在的 GitHub Pages

`lightsakuras.github.io` 在国内**电脑宽带**上经常能开，但**手机 4G/5G**上有很高概率打不开或极慢。
而这类整活网页的传播场景 100% 是「别人用手机点开你发的链接」——所以它不能当对外链接用。

它现在的价值是：自己的作品存档 + 我这边随时能验证 + 你电脑上能预览。**保留，但别发出去。**

## 二、几个候选为什么被排除（都查过官方文档）

| 方案 | 真相 |
|---|---|
| **腾讯云 EdgeOne Pages** | 默认域名要大陆加速只能用**3 小时有效的预览链接**，超时 401；选"全球（不含中国大陆）"则大陆网络直接 401。稳定必须绑**已备案**域名 |
| **腾讯云 CloudBase 静态托管** | 2025-10-09 后创建的环境，默认域名会有**中间提示页**长期存在；浏览器直访生产环境必须用备案域名 |
| **Gitee Pages** | 已经停服（现在只有付费的 Gitee Pages Pro / 企业版） |
| **阿里云 OSS / 腾讯云 COS 默认域名** | 不支持静态网站直接访问：要么变成下载，要么必须绑备案的自定义域名 |
| **Vercel / Netlify** | 国内访问极不稳定，部分网络直接不通 |

一句话：**它们不是"国内产品"，或者"允许直访"的那一档都要备案域名。**

## 三、三条现实路径（按推荐度）

### 方案 A｜今天能搞完，约 ¥30/年 —— 买域名 + Cloudflare Pages（**推荐**）

为什么不备案也能用：服务器在境外，域名解析在 Cloudflare，国内访问走 CF 节点。
关键点是**用自己的域名**——`*.pages.dev` 那个默认域名在国内部分运营商被 SNI 拦，换成自己的域名就绕开了。

步骤：

1. **买域名**（不需要备案，买了就能用）
   - 阿里云 / 腾讯云：`.top` `.xyz` `.icu` 首年 ¥10–40，续费 ¥30–80
   - 建议选短、好念、跟 ligsa 相关的，比如 `ligsa.top` `ligsa.icu`
2. **注册 Cloudflare**（免费，邮箱即可，不需要实名）
3. **把域名 NS 改到 Cloudflare**：Cloudflare 给你两个 NS 地址 → 回阿里云/腾讯云域名控制台 → 改 DNS 服务器 → 等 10 分钟–2 小时
4. **Cloudflare Pages → Create a project → Direct Upload** → 把 `ligsa-abstract-site.zip` 解压后整个文件夹拖上去 → Deploy
5. **Pages → Custom domains → 添加你的域名** → 它会自动帮你建 CNAME
6. **等 5–20 分钟**，打开 `https://你的域名/` 验证
7. **用手机 4G/5G 打开一次**（这一步才作数，别用家里 WiFi 判断）

成本：域名 ¥30/年，其余全免费。
风险：Cloudflare 在国内不是 100%，个别地区/时段会慢。**但这是"免备案"里的最优解。**

### 方案 B｜2–3 周，最稳 —— 域名备案 + 国内云

适合：你打算把 ligsa 长期做下去，链接要发给客户/大量陌生人。

1. 买域名 + 一台国内轻量服务器（腾讯云轻量 1H2G，学生机/活动机几十元一年）
2. 云厂商控制台 → **备案**（免费，个人备案约 2–3 周，需要身份证 + 幕布拍照）
3. 备案通过后，把 `ligsa-abstract-site.zip` 传到 **COS / EdgeOne Pages / CloudBase**，绑定这个备案域名
4. 结果：全国任何网络、**微信里 100% 能打开**，速度是 Cloudflare 的 3–5 倍

这是终局方案。前 2 周用方案 A 顶着，不冲突。

### 方案 C｜0 元，今天就能发 —— 码上掘金（临时）

不想现在花钱的话，用国内可直连的在线运行环境：

1. 打开 `code.juejin.cn`（掘金旗下，国内直连，不用梯子）
2. 新建一个「网页」代码块，把 `gongde/index.html` 的内容整段粘进去
3. 保存后拿分享链接，手机能直接打开、能敲木鱼

缺点：**页面外面有掘金的编辑器外壳**，不是纯净页面，显得不专业。
用途：**验证"朋友点开真的会玩"**，以及在没有域名前先跑通传播链路。不适合长期当对外主链接。

## 四、在此之前，内容怎么发（不用链接也能起号）

链接没解决，不代表不能发笔记。这三类内容天然不需要别人点开：

1. **录屏**：敲木鱼 15 秒，配文「凌晨两点我敲了 108 下」。视频流不依赖外链。
2. **结果图**：诊断书是 canvas 生成的图片，直接当笔记图发（"测出来我是已疯未遂 94%"）。
3. **评论区埋钩子**：「想测的扣 1 我私信你」——链接只走私信，不写在笔记里（写了限流）。

等链接好了，再把这些老笔记补一条评论「链接放了」，等于二次激活。

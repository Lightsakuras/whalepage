## 三、发出后 60 分钟

1. **立刻**用自己的小号（或朋友的号）搜标题，确认收录
2. **发一条首评**，15 字以上，别只发表情：
   ```
   第 6 个想做「一按就出梗图」的，有人想要吗
   ```
3. **5 分钟内**回复前 5 条评论（算法看首小时互动）
4. **置顶评论**放链接（正文里**绝对不要**放）：
   ```
   全部在这：ligsa.work
   手机浏览器打开就行，别在微信里点
   ```
5. 如果有人问怎么做的 → 别急着讲技术，先问「你想做什么样的」

## 五、红线（踩一条这篇就废）

| 不要做 | 为什么 |
|---|---|
| 正文里放链接 | 外链导流是最主要的限流原因 |
| 放二维码 | 同上，而且更容易被判营销 |
| 说「私信我发你」 | 手动导流，风险比放链接还高 |
| 一天发两条 | 新号一天一条，节奏比数量重要 |
| 追着人问「要不要定制」 | 第一篇只做曝光，不谈钱 |

## 六、数据判断（发布后 2 小时看）

| 现象 | 说明 | 下一步 |
|---|---|---|
| 曝光 < 300 | 没进流量池 | 换封面重发，同一篇内容 |
| 点击率 < 2.5% | 封面不行 | 封面上的字太大或太密，减字 |
| 完读 < 40% | 正文太长 | 删掉前两段，直接上编号 |
| 收藏率 > 5% | 内容有用 | 立刻追第 2 篇（同类型） |
| 涨粉 > 20 | 人设成立 | 把简介里的链接改得更显眼 |

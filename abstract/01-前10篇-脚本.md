## 06 · 教你 30 分钟做一个整活网页（教程，涨收藏）

**标题**
- 主：30 分钟做一个能发朋友圈的整活网页
- 备：不用框架、不用安装，一个 HTML 文件就够

**封面文案**：1 个 HTML 文件

**正文**
```
不用 React，不用 Vue，不用装环境。
新建一个 .html 文件，双击就能在浏览器打开。

做整活网页只需要三件事：
1. 一个能点的东西（按钮/图片/整块屏幕）
2. 一个会变的数字（功德、连击、分数）
3. 一张能保存的结果图（canvas 画出来）

第 3 步是命门——不能截图的东西没人传播。

canvas 出图核心就三行：
const c = document.createElement('canvas');
const x = c.getContext('2d');
x.fillText('你的分数', 100, 200);

想要完整代码的评论区说一声，我整理一份。
```

**标签**：#前端 #HTML #教程 #零基础 #整活

**首评**：我做的功德机源码结构很简单，想要的留个言，人多我就放出来。

## 发布后 60 分钟清单（每篇都做）

1. 0–5 分钟：自己发首评（正文里埋的问题，把答案放首评）
2. 5–30 分钟：回完所有评论，**每条都回**（评论权重 ×4）
3. 30–60 分钟：小号搜标题看有没有被收录；没有就改一次标题的尾部
4. 记录数据：曝光 / 点击率 / 收藏 / 评论 / 涨粉

## 数据怎么判断

| 现象 | 说明 | 动作 |
|---|---|---|
| 点击率 < 2.5% | 封面不行 | 换封面重发（隔 3 天） |
| 点击率 > 4% 但收藏低 | 内容没干货 | 加"可照做的步骤" |
| 收藏 > 点赞 | 内容有价值 | 这个方向继续做 3 篇 |
| 曝光高、涨粉少 | 主页不行 | 改简介、加置顶 |
| 评论多但都是"哈哈哈哈" | 纯乐子型 | 可以，但要多一篇"能拿走东西"的平衡 |
